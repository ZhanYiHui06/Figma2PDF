# PRD v1.1：Folio（中文名：对开）

> 状态：技术验证完成，第 10 节的待决问题已确认。下一步：UI 风格与原型 → spec → 开发。技术细节见 [spike-report.md](./spike-report.md)。

## 1. 定位

一个免费、开源（AGPL-3.0）的 Figma 插件。它把 Frame 导出成**能直接交给印刷厂**的多页 PDF：支持 RGB 和 CMYK（基于 ICC 转换），支持可视化排序，并自动做尺寸、出血、分辨率等印刷检查。

## 2. 目标用户

- **主要用户**：有印刷需求的半专业用户和运营人员，他们常被印刷厂要求提供 CMYK 文件。
- **次要用户**：做物料的专业设计师。
- **产品原则**：默认值要对；问题要主动提示，并且讲清原因；专业参数都收进"高级"。

## 3. 用户流程

选中 Frame / Section → 打开插件 → 查看页面列表（插件已自动展开和排序）→ 拖拽调整或移除页面 → 处理检查提示 → 设置色彩和出血 → 导出 → 下载 → 查看导出报告

## 4. 功能需求（MVP）

### F1 选区解析
- 只接受 Frame。选区里的其他对象会被忽略，并提示"已忽略 N 个非 Frame 对象"。
- 选中 Section 时，展开其中的 Frame，并递归展开嵌套的 Section。
- **容器 Frame 识别**（技术验证中新增）：如果一个 Frame 的子节点全部是 Frame，并且满足以下任一条件，就把它视为容器、展开成多页：
  - 它是 Auto Layout；
  - 它的子 Frame 尺寸一致；
  - 它自身尺寸不匹配任何纸张规格。

  展开后提示"已展开为 N 页"，并提供"作为单页导出"的切换。
- 重复选中的 Frame 自动去重。

### F2 页面列表与排序
- 每页显示：缩略图、名称、尺寸（mm）、纸张规格匹配结果。
- 支持拖拽排序和移除页面，提供"恢复默认顺序"按钮。默认顺序按画布位置排列（从上到下、从左到右）。排序结果不持久化。

### F3 尺寸检查与缩放
- 换算关系：1px = 1pt = 0.3528mm。
- 和常见纸张规格比对，容差 ±1mm。规格包括：A 系列、B 系列、大度 / 正度开本、名片等。
- 尺寸不匹配时提示原因，并提供"按目标纸张等比缩放导出"。
- 宽高比误差在 1% 以内才允许缩放；超过时只能选择"居中放置、四周留白"，或者不缩放。
- 缩放后重新检查：最细线条是否小于 0.25pt、最小字号、图片有效分辨率。
- 各页尺寸不一致时，导出前弹窗确认，用户确认后放行。

### F4 色彩
- RGB 或 CMYK。
- **ICC 采用"用户自带"模式**（不内置受版权约束的 ICC，由用户自己提供并承担授权）：
  - 内置一个默认配置：「通用 CMYK（近似 SWOP）」，来自 Ghostscript 自带的 `default_cmyk.icc`，AGPL 授权。界面上要如实标明"近似"。
  - 导入 ICC：上传 `.icc` 或 `.icm` 文件后，插件自动校验并识别：
    - 必须是 CMYK 色彩空间，设备类别是输出设备（prtr）；
    - 显示名称从文件的 `desc` 标签读取（v2 和 v4 格式的 `mluc` 都要支持）；
    - 按内容哈希去重。
  - 导入的 ICC 保存在本地，在列表中显示，可以删除，可以设为默认。
  - 存储上限：插件的 `clientStorage` 一共只有 5MB，常见 ICC 每个大约 0.5～2MB，所以存储前先压缩，并在界面上显示已用空间。存满时提示用户删除旧的配置。
  - 本地存储按"设备 + 客户端"区分，在其他电脑或换用网页版时需要重新导入。这一点要在界面上说明。
  - 提供获取指南：Windows / macOS 系统里已有 ICC 的路径；Adobe 和 ECI 的官方下载页；"向你的印刷厂索取"。
- **纯黑文字转单 K**：默认开启。只处理文字节点，并且颜色要同时满足两个条件：中性灰（RGB 三个通道最大值减最小值 < 0.03），且最亮的通道 ≤ #333333。背景和大面积色块不处理（原因见技术验证报告第 3 节）。

### F5 出血（方式 A，默认关闭）
- 前提：Frame 尺寸就是成品尺寸。出血默认 3mm，可以修改。
- 插件在导出时把 Frame 的背景色延伸到出血区，并导出 Frame 外出血范围内的内容。
- 写入 TrimBox / BleedBox；裁切标记可选，默认关闭。
- **贴边检测**：如果某个元素贴着成品边缘、却没有延伸到出血区，就给出提示。
- 在开关旁说明："印刷厂要求出血时再开启"。

### F6 分辨率预检
- 按 `scaleMode` 和实际变换计算每张图片的有效 ppi。低于 300 时警告，低于 150 时严重警告。
- 高级选项：图片降采样上限，用来控制文件体积。

### F7 导出
- 两种方式：合并成单个 PDF，或每页一个 PDF 打包成 zip。zip 里的文件以 Frame 名称命名，非法字符会被替换，重名时追加序号。
- 文字保持可选中（Figma 原生行为：可见部分是矢量轮廓，上面叠一层不可见文字）。
- 分阶段进度条（导出 → 合并 → 转换），支持取消。
- 导出报告：页数、色彩配置、提示条数。

### F8 资源加载
- Ghostscript WASM 和 ICC 文件在线加载，使用国内和国外两个 CDN 自动切换，所有文件做 SHA-256 校验。
- 首次使用 CMYK 时需要下载约 11MB，界面上要显示下载进度。
- RGB 导出不依赖网络。

### F9 界面语言
- 中英双语，跟随 Figma 的界面语言，也可以手动切换。

## 5. 不做

专色、编辑 CMYK 数值、服务端处理、排序持久化、PDF/X 合规认证（放到 v2）、大面积四色黑配方（放到 v2）。

## 6. 非功能需求

- 全程在本地处理，不上传设计文件。
- 16 页 A4 的 CMYK 导出时间小于 30 秒（需要在浏览器中实测校准）。
- 兼容 Figma 桌面端和网页端。
- 导出过程中创建的临时节点必须在 `finally` 里删除，不能残留在用户文件中。

## 7. 技术路线（已验证）

1. 每个 Frame 克隆一份临时节点。在克隆上处理出血容器、文字近黑色改成标记色，然后用 `exportAsync(PDF)` 导出，最后删除临时节点。
2. 在 PDF 层把标记色替换成 `0 0 0 1 k`。
3. 用 pdf-lib 合并页面、缩放、写入页面框。
4. 用 Ghostscript WASM 配合 ICC 转换成 CMYK。
5. 用 JSZip 打包，交给浏览器下载。

## 8. 成功指标

- 导出成功率 > 98%。
- 印刷厂退件率：通过导出报告里的反馈入口收集。
- 7 日留存、导出次数。

## 9. 交付方式

- 由 Claude 一次性实现，并把构建产物提交到仓库，用户通过"从 manifest 导入"在 Figma 中安装。
- 交付时附带手动测试清单，由用户逐项验收。

## 10. 已确认决策

- Q1 产品名：Folio / 对开（上架前还要到 Figma 社区查重）。
- Q2 容器 Frame 识别规则：认可。
- Q3 ICC：用户自带，本地保存，自动识别名称。
- Q4 单 K 阈值：中性灰，且最亮通道 ≤ #333333。
