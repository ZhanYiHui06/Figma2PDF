# 手动测试清单

在 Figma 桌面版里按“从 manifest 导入”安装后逐项验收。建议用技术验证用的《冶金机械 A4 中文版》文件。

## 选区与页面列表
- [ ] 什么都不选：显示空状态，导出按钮禁用，底部有 px→mm 提示。
- [ ] 只选编组 / 图片：空状态里提示“已忽略 N 个非 Frame 对象（编组、图片）”。
- [ ] 选中 Section「V2 / 冶金机械 — A4 中文版」：展开为 16 页，顶部蓝色提示“已将「中文版手册 — 16页」展开为 16 页”。
- [ ] 点“改为作为单页导出”：变成 1 页（10484 × 842），再点“改为展开成多页”恢复。
- [ ] 同一个 Frame 多选或被 Section 重复包含时只出现一次。
- [ ] 默认顺序是画布上从上到下、从左到右。
- [ ] 列表视图拖动 ⋮⋮ 手柄排序，插入位置有朱红横线；网格视图拖动卡片，原位置变虚线空位、卡片浮起。
- [ ] 悬停一行出现 ×，点击只移除本次导出（画布不变）；“恢复默认顺序”恢复顺序和被移除的页。
- [ ] 缩略图正确显示。

## 检查
- [ ] 封面、公司简介、品牌标语行尾显示 ppi 标签（约 137 / 157 ppi）。
- [ ] 点击行进入详情，“在画布中定位图层”会选中并缩放到图片图层，插件页面列表不因此清空。
- [ ] 新建一个 210 × 297 px 的 Frame：标签显示“仅 A7 大小”，详情里可选“按 A4 等比放大导出”，放大后 ppi 重新计算。
- [ ] 宽高比不符的 Frame（如 300 × 300）选 A4：只能“居中放到 A4，四周留白”。
- [ ] 各页尺寸不一致时导出会弹窗确认。

## 色彩
- [ ] 切换 RGB / CMYK，摘要文字随之变化。
- [ ] ICC 管理：导入 CMYK 输出配置（如印刷厂给的 .icc），名称从文件里读出；重复导入提示已导入过。
- [ ] 导入 sRGB 显示器配置：提示“是 RGB 显示器配置文件，不能用于 CMYK 导出，未导入”。
- [ ] 删除、设为默认；内置配置不能删除；本地空间用量随之变化。
- [ ] 关闭插件再打开，导入的 ICC 和设置都还在。

## 出血
- [ ] 默认关闭；开启后可改宽度、加裁切标记。
- [ ] 有贴边元素的页显示“贴边”提示，汇总条“N 页有贴边元素……”点“查看”进入对应页。
- [ ] 导出 PDF 在 Acrobat 里查看：TrimBox = 成品尺寸，BleedBox 每边多 3mm，背景延伸到出血区，Frame 外 3mm 内的内容出现在出血区。
- [ ] 勾选裁切标记：四角有标记线，不压到出血区。

## 导出
- [ ] RGB 合并导出：不显示“下载色彩引擎”和“转换”步骤，文字可选中复制。
- [ ] 首次 CMYK 导出：显示引擎下载进度（约 11MB），之后同一会话不再下载。
- [ ] CMYK 导出后在 Acrobat 输出预览里：颜色都是 CMYK；近黑文字是单 K（C0 M0 Y0 K100），深色背景仍是四色黑。
- [ ] 使用导入的 ICC 导出，报告“色彩”一栏显示该配置名称。
- [ ] 每页一个 PDF（zip）：文件以 Frame 名称命名，重名追加 (2)。
- [ ] 下载的文件名是中文名（如“中文版手册 — 16页.pdf”），不是 download。
- [ ] 导出中点“取消”：回到主界面，画布上没有残留的临时节点（检查图层面板和“Folio · 出血”）。
- [ ] 导出完成页：页数、文件大小、尺寸、色彩、单 K 处理数、出血都正确；“再次下载”可用；未处理的提示列在黄色框里。
- [ ] “印刷厂退回了文件？”打开 GitHub 反馈页。
- [ ] 16 页 A4 CMYK 导出耗时（记录实际秒数，目标 < 30 秒）：____ 秒。

## 其他

- [ ] 拖动右下角调整窗口大小；展开设置时窗口自动拉高。
- [ ] Figma 网页版同样可用。
